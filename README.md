# 🐂 BOSS BULL007 — AI Institutional Trading Desk (Prototype v1)

> **Coordinated by Boss-Bull007**  
> An institutional trading team powered by specialized AI divisions, purpose-built for Indian Equities (NSE/BSE) paper trading.

---

## 🏛️ The 6-Division Desk Structure

1. **👔 Boss (Bull007)**: Operations coordinator, strategic synthesis, and desk governance.
2. **🔎 Market Researcher**: Scans NSE/BSE stocks, plots dynamic candlestick charts, EMAs (9 & 21), VWAP, and RSI.
3. **📰 News Analyst**: Translates global Geopolitics, Brent Crude, DXY, and FII/DII liquidity trends into sector biases.
4. **📋 Strategist**: Generates systematic intraday trade plans with a strict minimum 1:2 Risk-to-Reward ratio.
5. **🛡️ Risk Manager**: Ironclad capital preservation with automated position sizing and trade veto powers (1% max risk rule).
6. **📈 Paper Trading Ledger**: Realistic simulated order execution, open position tracking, and performance analytics.

## 🚀 How to Run Locally (Laptop / PC)

### 1. Requirements
Ensure Python 3.10+ is installed on your computer. If not yet installed, download it from [python.org](https://www.python.org/downloads/) or via Windows Terminal:
```powershell
winget install Python.Python.3.12
```

### 2. Install Dependencies
Open a PowerShell or Command Prompt inside this folder:
```powershell
pip install -r requirements.txt
```

### 3. Launch the Trading Desk
```powershell
streamlit run app.py
```
Your browser will open automatically at `http://localhost:8501`.
